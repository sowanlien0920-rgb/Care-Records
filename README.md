# 訪問介護 サービス実施記録

訪問介護のサービス実施記録をブラウザ上で作成・管理するための、単一 HTML ファイルのアプリです。
データはブラウザの localStorage に保存され、サーバーへの送信は行いません。

## 使い方

### そのまま開く
`index.html` をダブルクリックしてブラウザで開きます。音声入力以外の機能はすべて使えます。

### ローカルサーバー経由で開く（音声入力を使う場合）
`サーバーで起動.cmd` を実行します（Python が必要）。
`http://localhost:8765/index.html` が開きます。

> 直接開いた場合とサーバー経由の場合で、ブラウザはデータを別々に保存します。
> 引き継ぐときは「バックアップファイルを保存」→「バックアップから復元」を使ってください。

## 主な機能

- サービス実施一覧 / 未完了の訪問の管理
- 記録画面（バイタル・実施内容・特記事項、音声入力対応）
- 承認フロー（未承認一覧）
- 利用者マスタ、月間帳票、ヒヤリハット報告

## ビルド

```
node build.js
```

`index.html` から Artifact 共有用の `dist/app.html` を生成します。
ローカルで使うファイルは `index.html` のままで変更ありません。

## 画面

`画面キャプチャ/` に各画面のスクリーンショットがあります。
